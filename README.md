# Salsbury Computational Biophysics Group

Public website for the Salsbury Group in the Department of Physics at Wake Forest University.

The site is built with Jekyll and AcademicPages and published through GitHub Pages at <https://salsburygroup.github.io/>.

## Content policy

The website describes stable, publicly documented research areas and selected peer-reviewed publications. Confidential collaborations, unpublished results, and internal project details are intentionally excluded.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

## Updating

- Site settings and profile links: `_config.yml`
- Main navigation: `_data/navigation.yml`
- Page content: `_pages/`
- Visual styles: `assets/css/main.scss`
