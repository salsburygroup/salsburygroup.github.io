Computational science depends on transparent, testable workflows. We aim to document assumptions, preserve the connection between inputs and results, and make code public when it is suitable for release.

## Reproducible by design

<div class="feature-grid feature-grid--three">
  <article class="feature-card">
    <h3>Traceable</h3>
    <p>Inputs, parameters, software versions, and analysis choices should be recoverable.</p>
  </article>
  <article class="feature-card">
    <h3>Validated</h3>
    <p>Numerical stability, sampling, and sensitivity checks are part of the scientific result.</p>
  </article>
  <article class="feature-card">
    <h3>Shareable</h3>
    <p>Released workflows should be understandable beyond the person who originally wrote them.</p>
  </article>
</div>
